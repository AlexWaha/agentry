## Agentry v0.2.0

Agentry is now a Claude Code plugin you install from this repository.

### What's new

- The tools, skills and hooks moved into a plugin under `plugin/`: 42 skills and 46 hooks on seven events (`SessionStart`, `PreToolUse`, `Stop`, `SubagentStart`, `SubagentStop`, `PreCompact`, `PostToolUse`). Every script is standard-library Python.
- A GitHub marketplace manifest at `.claude-plugin/marketplace.json`. The plugin version is semver, set in `plugin/.claude-plugin/plugin.json`, and a release is a version bump, a changelog entry and a `vX.Y.Z` tag.
- Verified install from GitHub: `agentry@agentry` installs from an anonymous HTTPS clone, runs from the cached copy, and a headless session from that copy denies a `/dev/null` redirect and a write by an unresolved agent.
- README guide for install, version pinning per project, upgrade and rollback, plus a `CHANGELOG.md`.

### Gates and agents

- A task moves between stages only when `advance.py` runs the stage's exit command and reads a real exit code. State lives in `.agentry/state/run.db`.
- 31 role agents with three gate profiles (`dev`, `docs`, `readonly`), enforced by `agent_gate.py` inside each subagent.
- Commit and push stay behind a recorded human approval.

### Install

Run from your project root, then restart Claude Code:

```bash
claude plugin marketplace add AlexWaha/agentry --scope local
claude plugin install agentry@agentry --scope local
```

Requires Claude Code, Python 3.12 or newer, and git. The plugin ships the tools, skills and hooks. To set up a project, copy `.claude/`, `.agentry/` and `CLAUDE.md` from this repository, then run the onboarding prompt in the README. Agents and rules come from `.claude/`; the pipeline config, project overlay and task templates come from `.agentry/`.

Status: verified on Claude Code 2.1.299 with HTTPS forced (`CLAUDE_CODE_PLUGIN_PREFER_HTTPS=1`). If you have no SSH key for GitHub, set it before the first command.

### Pin a version

```bash
claude plugin marketplace add AlexWaha/agentry#v0.2.0 --scope local
claude plugin install agentry@agentry --scope local
```

The ref after `#` goes to `git clone --branch`, so a tag or branch works and a commit SHA does not. A version suffix such as `agentry@agentry@0.2.0` is silently ignored. Re-running `marketplace add` for the existing `agentry` marketplace prints "already on disk" and changes nothing; to move a pinned project to another tag, remove and re-add as in Roll back.

Status: measured with a branch (`#main`) on Claude Code 2.1.299; the tag form is pending the first tag. A local-scope install should stay on its installed version until `plugin update`, and a push to `main` should change nothing for it; not yet measured across a real version bump.

### Upgrade

```bash
claude plugin marketplace update agentry
claude plugin update agentry@agentry --scope local
```

Status: on 2.1.299, `marketplace update` keeps the ref pin and `plugin update` at the same version prints "already at the latest version". Upgrade across a real version bump from GitHub is not yet measured.

### Roll back

```bash
claude plugin uninstall agentry@agentry --scope local
claude plugin marketplace remove agentry --scope local
claude plugin marketplace add AlexWaha/agentry#v<previous> --scope local
claude plugin install agentry@agentry --scope local
```

Restart Claude Code afterwards. Warning: `marketplace remove` cascades and uninstalls every plugin from that marketplace at every scope.

Status: all four commands exit 0, measured on 2.1.299 with a branch ref; the tag form is pending the first tag.

Full changelog: https://github.com/AlexWaha/agentry/blob/main/CHANGELOG.md
