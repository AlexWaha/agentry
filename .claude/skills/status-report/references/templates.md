# Status Report Templates

Phase deliverables table and the full output skeleton for the status-report
skill. Read this when actually assembling the output.

## Phase deliverables

For the current phase (and any recently completed phase), check that these
files exist, are non-empty, and are up to date. Mark each Present / Missing /
Incomplete.

| Phase | Expected Deliverables |
|-------|----------------------|
| 1 | `docs/business/product-vision.md`, `docs/business/target-audience.md`, `docs/business/user-personas.md` |
| 2 | `docs/market/market-research.md`, `docs/market/competitive-landscape.md`, `docs/market/positioning.md` |
| 3 | `docs/business/business-plan.md`, `docs/business/revenue-model.md`, `docs/business/unit-economics.md` |
| 4 | `docs/finance/financial-model.md`, `docs/finance/projections.yaml`, `docs/finance/breakeven-analysis.md` |
| 5 | `docs/product/whitepaper.md`, `docs/product/product-spec.md`, `docs/product/user-flows/` |
| 6 | `docs/technical/architecture.md`, `docs/technical/db-schema.md`, `docs/technical/api-contracts.md`, `docs/technical/tech-stack.md` |
| 7 | `project/docker-compose.yml`, CI/CD configs, environment setup |
| 8 | Working code in project source tree and test suites |
| 9 | Test suites, quality reports in `docs/technical/` |
| 10 | React Native app in `frontend/` |
| 12 | `docs/marketing/marketing-plan.md`, landing page specs |
| 13 | `docs/risk/risk-matrix.md`, `docs/risk/mitigation-plan.md` |
| 14 | `docs/growth/growth-strategy.md`, `docs/growth/scaling-plan.md`, `docs/growth/roadmap.md` |

A phase is "complete" when every task assigned to it is in
`.claude/tasks/done/`, every expected deliverable above exists in `docs/`,
and CEO approval is noted in the epic or task completion notes.

## Output skeleton

```markdown
# Project Status Report

**Date:** [current date]
**Generated by:** Orchestrator

---

## Phase Status

| Phase | Name | Status | Deliverables |
|-------|------|--------|-------------|
| 1 | Ideation | [Complete/In Progress/Not Started] | [X/Y present] |
| 2 | Market Research | [status] | [X/Y present] |
| ... | ... | ... | ... |

**Current Phase:** Phase [N] - [Name]
**Phase Progress:** [X]% complete ([done tasks] / [total phase tasks])
**Expected Deliverables:** [list]
**Missing Deliverables:** [list or "None"]

---

## Task Summary

| Metric | Count |
|--------|-------|
| Total Tasks | [N] |
| Active | [N] |
| Done | [N] |
| Blocked | [N] |
| Completion | [N]% |

---

## Completed This Session

| # | Title | Phase | Branch |
|---|-------|-------|--------|
| [task id] | [title] | [phase] | [branch name] |

(If no tasks were completed this session, state "No tasks completed in this session.")

---

## In Progress

| # | Title | Phase | Assignee | Branch | Notes |
|---|-------|-------|----------|--------|-------|
| [task id] | [title] | [phase] | [agent] | [branch] | [brief status note] |

---

## Blockers

| Task | Blocker | Duration | Resolution |
|------|---------|----------|------------|
| [task id] | [what is blocking] | [how long] | [suggested fix] |

(If no blockers, state "No blockers identified.")

---

## Risks

| Risk | Severity | Details |
|------|----------|---------|
| [risk] | [High/Medium/Low] | [explanation] |

(If no risks, state "No new risks identified.")

---

## Next Steps

1. [Recommended next action with assignee]
2. [Second action]
3. [Third action]

---

## Recommendations

[Any strategic recommendations based on the status analysis - e.g., "Consider
starting Phase 3 planning while Phase 2 tasks are being finalized to maintain
momentum."]
```
